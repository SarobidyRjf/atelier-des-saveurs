    Erreurs & résolutions

    • Erreur : dossiers modules/nk_clickcollect et themes/atelier vides dans le conteneur.
      Cause : conteneur relancé au démarrage de Windows avant la distribution WSL (restart: unless-stopped).
      Résolution : docker compose up -d --force-recreate prestashop + healthcheck et restart: "no".
    • Erreur : transporteur du module absent des choix au checkout.
      Cause : un transporteur de module n'est retenu que si need_range = 1 (filtre is_module = 0 OR need_range = 1).
      Résolution : need_range = true ; sans effet sur le prix car is_free renvoie 0 avant tout calcul (source : classes/Carrier.php:570, classes/Cart.php:3787).
    • Erreur : back-office en erreur 500 — appParameters.php introuvable.
      Cause : bin/console lancé en root a reconstruit var/cache/dev en root, illisible pour www-data.
      Résolution : chown -R www-data:www-data var/cache ; désormais docker exec -u www-data … bin/console.
    • Erreur : nom du module affiché « Click &amp; Collect ».
      Cause : $this->l() applique htmlspecialchars (source : classes/Translate.php:209).
      Résolution : nom propre écrit sans l() (il n'a pas à être traduit).
